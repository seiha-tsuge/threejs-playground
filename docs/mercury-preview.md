# 水星の実描画確認

- `mercury-scene-demo.png`: アプリの初期カメラで撮影した全体配置。太陽の右隣の小さな天体が水星、その右が地球。
- `mercury-surface-demo.png`: 同じ `createSpaceScene` のメッシュ・配置・照明を使い、カメラだけ水星に近づけた実描画。加工・合成はしていない。

全体画面は `pnpm dev` で確認する。近接画面は以下で起動する。

```sh
pnpm exec vite --config docs/mercury-preview.config.mjs
```

`http://127.0.0.1:5174/docs/mercury-preview.html` を WebGPU 対応ブラウザで開く。撮影時のビューポートは 1280 × 720。通常のアプリには近接カメラ設定を適用していない。

距離スケールは 2、惑星半径スケールは 0.1。太陽の半径 0.5 に対し、水星の内縁は `0.387 × 2 − 0.383 × 0.1 = 0.7357` なので重ならない。地表は色によるクレーター表現であり、形状の凹凸は追加していない。
